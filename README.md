# 🎓 Vodro AI (ভদ্র AI) - English Teacher Chatbot

**Vodro AI** হলো বাংলাভাষীদের জন্য বিশেষভাবে তৈরি একটি অত্যন্ত বিনয়ী, মিষ্টি ও উৎসাহব্যঞ্জক কৃত্রিম বুদ্ধিমত্তা সম্পন্ন ইংরেজি শিক্ষক চ্যাটবট।

---

## 🌟 প্রধান সুবিধাসমূহ (Key Features)

1. **ভদ্র ও মার্জিত ব্যক্তিত্ব (Polite Persona):**
   - কোনো ভুলে কখনো ব্যঙ্গ বা উপহাস করে না।
   - পরম স্নেহে ও উৎসাহ দিয়ে ভুল শুধরে দেয়।

2. **ভুল সংশোধন ও বাংলা ব্যাকরণ ব্যাখ্যা (Grammar Doctor):**
   - ব্যবহারকারীর লেখা বাক্যের ব্যাকরণ পরীক্ষা করে।
   - আপনার বাক্য vs সঠিক রূপ vs ভদ্র বিকল্প প্রদর্শন করে।
   - কেন এমন হলো তা সহজ বাংলায় স্পষ্ট বুঝিয়ে দেয়।

3. **৫টি বিশেষ অনুশীলন মোড (Practice Modes):**
   - ☕ **Casual English:** সাধারণ দৈনন্দিন জীবনের আড্ডা।
   - 💼 **Job Interview:** চাকরির ইন্টারভিউ প্রশ্ন ও মার্জিত উত্তরের প্রস্তুতি।
   - 🩺 **Grammar Doctor:** যেকোনো বাক্য পুঙ্খানুপুঙ্খ পরীক্ষা।
   - 🇧🇩 **Bangla to English:** বাংলায় মনের ভাব লিখলে তার ভদ্র ইংরেজি রূপ শেখা।
   - 🍽️ **Restaurant & Travel:** বিদেশ ভ্রমণ, হোটেল ও রেস্টুরেন্টে কথা বলার কৌশল।

4. **ভয়েস ও উচ্চারণ (Voice & Pronunciation):**
   - 🎙️ **Speech to Text:** মাইক্রোফোন চেপে মুখে ইংরেজিতে কথা বলার সুবিধা।
   - 🔊 **Text to Speech:** ব্রিটিশ, আমেরিকান এবং ভারতীয় এক্সেন্টে নির্ভুল উচ্চারণ শোনার সুযোগ।

5. **টুলস ও টেস্ট (Tools & Quiz):**
   - ⚡ **Quick Quiz:** ঝটপট গ্রামার কুইজ ও তাৎক্ষণিক ব্যাখ্যা।
   - 📚 **Word of the Day:** প্রতিদিনের মার্জিত ইংরেজি শব্দ, ফোনেটিক্স ও উদাহরণ বাক্য।

6. **Gemini API Integration (ঐচ্ছিক):**
   - চ্যাটবটটির সমৃদ্ধ নিজস্ব **In-built Smart Brain** রয়েছে, যা কোনো ইন্টারনেট এপিআই ছাড়াই দ্রুত কাজ করে।
   - চাইলে Settings থেকে আপনার নিজস্ব **Gemini API Key** যুক্ত করে আনলিমিটেড লাইভ জেমিনি মডেলের সাথেও কথা বলতে পারেন।

## 🚀 কীভাবে চালু করবেন (How to Run)

1. এই ফোল্ডারে টার্মিনাল খুলুন:
   ```bash
   cd C:\Users\user\.gemini\antigravity-ide\scratch\vodro-ai-chatbot
   ```

2. যেকোনো লোকাল সার্ভার চালু করুন (যেমন পাইথন):
   ```bash
   python -m http.server 8123
   ```

3. ব্রাউজারে যান:
   ```
   http://localhost:8123
   ```
   অথবা সরাসরি `index.html` ফাইলটি যেকোনো আধুনিক ব্রাউজারে (Google Chrome / Microsoft Edge) ডাবল ক্লিক করে খুলুন।
